# 🛍️ Loja Online - Portfólio

Este projeto é uma **Loja Online** desenvolvida como parte do meu portfólio.
O objetivo é simular uma experiência de e-commerce simples, com funcionalidades de carrinho de compras, filtros de produtos e sistema de pagamento via PIX.

---

## 🚀 Funcionalidades

* Listagem de produtos com imagens, preços e categorias
* Filtro por nome e categoria
* Carrinho de compras dinâmico:

  * Adicionar e remover produtos
  * Cálculo automático do total
  * Salvamento automático com **localStorage**
* Checkout com pagamento via **PIX**:

  * Código copiável para pagamento
  * Confirmação antes de finalizar a compra
* Layout responsivo (funciona em celular e computador)

---

## 🖼️ Tecnologias utilizadas

* **HTML5** → estrutura do site
* **CSS3** → estilo e responsividade
* **JavaScript** → lógica do carrinho, filtros e pagamento

---

## 📱 Responsividade

O site foi desenvolvido para funcionar em qualquer dispositivo:

* 💻 **Computador:** produtos em grade + carrinho ao lado
* 📱 **Celular:** produtos em coluna + carrinho abaixo
